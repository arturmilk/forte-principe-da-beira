# A Planta Perdida de Sambuceti

Aventura histórica em primeira pessoa no **Real Forte Príncipe da Beira** (Costa Marques, RO), agosto de 1783.
Modelo 3D em escala 1:1, personagens 2D realistas (estilo Doom), diálogos sobre a rotina do forte, minigames e enigmas. Roda no navegador, inclusive no celular.

- `index.html` — o jogo
- `visualizador.html` — visualizador 3D livre do forte

Dramatização histórica: personagens documentados são Ricardo Franco de Almeida Serra, Luís de Albuquerque, José de Melo de Souza Castro e Vilhena, Domingos Sambuceti e Inácio Batista; os demais são fictícios. Sprites e texturas gerados no Higgsfield. Three.js via CDN.
